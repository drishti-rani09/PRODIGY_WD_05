# 🌦️ Weather App

A responsive Weather App built using HTML, CSS, and JavaScript that displays real-time weather information for different cities.

## ✨ Features

- Search weather by city name
- Display current temperature in Celsius (°C)
- Display weather conditions with emojis
- Show humidity percentage
- Show wind speed in km/h
- Default weather for Bengaluru
- Loading message and error handling
- Responsive design for mobile and desktop
- Search using Enter key

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Open-Meteo Geocoding API
- Open-Meteo Weather Forecast API

## 🌐 API Integration

This project uses Open-Meteo APIs to fetch weather information.

- Geocoding API: Retrieves latitude and longitude of the searched city.
- Weather Forecast API: Fetches current weather details using geographical coordinates.

No API key is required.
